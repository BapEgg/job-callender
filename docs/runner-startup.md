# 로그인 시 실행기 자동 시작

준비한 예약 작업 이름은 `JobCallender-Runner`입니다. 현재 Windows 계정이 로그인할 때 프로젝트의 `scripts/start-runner.ps1`을 숨김 창으로 실행합니다. Node와 Codex는 등록 당시 확인한 실행 파일의 절대 경로를 사용합니다.

- 현재 계정의 일반 권한으로만 실행하며 비밀번호를 저장하지 않습니다.
- 같은 예약 작업이 이미 실행 중이면 또 시작하지 않습니다. 시작 스크립트도 프로젝트별 잠금으로 중복 실행을 막습니다.
- 스크립트 잠금은 같은 로그인 세션에서만 적용됩니다. 직접 `node runner/main.mjs`를 실행하면 잠금을 거치지 않으므로 등록 후에는 예약 작업 또는 시작 스크립트를 사용합니다.
- PC를 깨우거나 로그인 화면에서 실행하지 않습니다. Docker가 아직 준비되지 않았으면 실행기가 30초 간격으로 연결을 다시 확인합니다.
- 실패한 예약 작업은 1분 간격으로 최대 3회 다시 시작합니다. 검색/API 장애의 재연결과는 별개입니다.
- Windows 실행 정책을 변경하거나 우회 옵션을 지정하지 않습니다. 기본 Windows PowerShell은 현재 파일 실행이 차단되어, 시험을 통과한 기존 Codex 런타임의 PowerShell 경로를 사용합니다. 해당 런타임이나 Codex 경로가 바뀌면 등록 내용을 다시 확인해야 합니다.

등록 전 미리보기는 `scripts/register-runner-startup.ps1`입니다. `-Install`을 명시한 경우에만 등록하며 같은 이름의 작업이 있으면 덮어쓰지 않고 중단합니다. 현재는 등록 전입니다.

사용자 승인 후 등록 → 기존 수동 실행기에 진행 중 작업이 없는지 확인 → 기존 실행기를 종료 → 예약 작업을 한 번 직접 실행 → 연결 및 당일 검색·알림 중복 여부 확인 순서로 검증합니다. 이 시험은 실제 로그아웃/로그인이나 절전 복귀 검증을 대신하지 않습니다.

자동 시작을 끄려면 Windows 작업 스케줄러에서 `JobCallender-Runner`를 찾아 **사용 안 함**으로 바꿉니다. 이미 동작 중인 실행기는 별도 종료해야 합니다. DB와 원본 파일은 그대로 남습니다.
